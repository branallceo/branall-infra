# branall-infra
브랜올 매체 인프라 소개서 웹 뷰어 (피트페이퍼 대체) - infra.branall.co.kr

## PDF 다운로드
- 각 소개서 왼쪽(모바일은 위쪽)의 'PDF 다운로드' 버튼은 pdf/{소개서이름}.pdf 파일을 내려받는다 (예: pdf/main.pdf, pdf/x-rt.pdf).
- 소개서 내용(이미지, 단가, 문구)을 바꾸면 PDF도 다시 만들어 같은 이름으로 올리고, docs.js의 DOCS_VERSION을 바꿔야 방문자가 새 PDF를 받는다.
- main.pdf는 HTML 슬라이드(deck-main.js)를 1920x1080으로 인쇄해 만든 것이고, 나머지는 img/{slug}-{n}.webp를 JPEG로 바꿔 묶은 것이다.
